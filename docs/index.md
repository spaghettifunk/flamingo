# Flamingo Documentation

Flamingo is a terminal-based modal text editor written in Zig. The repository includes the editor core, buffer model, virtual-screen renderer, file explorer and picker flows, search, TODO and comments panels, Git status and Git Graph views, syntax highlighting, LSP client plumbing, an integrated terminal panel, tests, and a rendering performance benchmark.

## Documentation Status

These docs describe the current repository state. Flamingo is still early-stage, so some pages are intentionally marked `Partial` or `TODO: verify` where behavior is incomplete or still evolving.

The documentation is intentionally plain Markdown for now. There is no MkDocs, Docusaurus, website app, GitHub Pages setup, or deployment workflow in this docs tree.
